# CyberTom VPN Client

Welcome to the CyberTom VPN client repository! This repository contains the source code for the official CyberTom VPN clients, which allow users to connect to the VPN network and access its services. The clients are available for Android, iOS, and macOS platforms.

## About
The CyberTom VPN client provides a secure and reliable way to connect to the CyberTom VPN network. It supports multiple operating systems and is built with security and performance in mind. The client handles tasks such as connecting to forwarding planes, managing user sessions, and ensuring encrypted communication between the user and the VPN network.

## Platform Support
- **Android**: Client for Android devices.
- **iOS**: Client for iPhone and iPad.
- **macOS**: Client for Mac computers.

## Features
- Secure VPN connection using industry-standard protocols.
- Easy-to-use interface for managing VPN sessions.
- Support for multiple VPN profiles and configurations.

## Installation

### Android
The Android client can be installed via:
1. Google Play Store (production release).
2. APK file (for development builds).

### iOS
The iOS client is available on the App Store or can be built from source using Xcode.

### macOS
The macOS client can be downloaded as a .dmg file or built from source using Xcode.
